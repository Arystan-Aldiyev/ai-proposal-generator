# CNS Proposal — Skill

## Когда срабатывает

Триггеры (любой из):

1. Пользователь присылает текст брифа клиента CNS Agency на естественном
   языке (русский): «Здравствуйте, нам нужен сайт…», «У меня магазин X,
   хочу бота…», «Сколько будет стоить редизайн?» и т.п.
2. Пользователь даёт структурированное ТЗ (длинный документ с разделами:
   цели, скоуп, требования, технологии).
3. Пользователь просит «оценить проект», «прикинуть смету», «дать
   диапазон», «найти аналог в нашем портфолио».

Если запрос — общий «расскажи про LLM-инжиниринг» или «как работает RAG»
— skill **не применяется**, отвечайте напрямую.

## Что делает

Не позволяет ассистенту галлюцинировать цены и сроки. Все цифры в КП
обязаны быть привязаны к реальной истории агентства. Skill заставляет
пройти три шага через MCP-сервер `cns-proposal`:

### Шаг 1 — Поиск аналогов

Сначала вызвать `search_analogues(query, k=3)` с описанием задачи на
русском. Получить 3 ближайших проекта-аналога с косинусной близостью
(score 0..1).

**Правило интерпретации score**:
- ≥ 0.65 — сильный аналог, можно опираться напрямую
- 0.55–0.65 — средний, использовать как ориентир
- < 0.55 — слабый, **обязательно** оговорить в КП, что прямого аналога
  нет, и оценка построена на допущениях

### Шаг 2 — Чтение карточек

Если нужны подробности конкретного проекта (объём работ, состав команды,
длительность, фактическая цена), вызвать `get_project_card(project_id)`.
**Никогда** не выдумывать поля карточки.

### Шаг 3 — Оценка

Для быстрой сметы (без полного КП) вызвать
`estimate_from_brief(brief)` — он сам прогонит Spec Extractor + RAG +
Estimator и вернёт структурированную смету с 2–3 вариантами,
рекомендацией и графиком оплаты.

Для полноценного КП с текстами и рисками — открыть веб-интерфейс на
http://localhost:8000 и нажать «Сгенерировать», там работает полный
LangGraph-пайплайн.

## Что нельзя

- ❌ Придумывать цифры цен и сроков. Если MCP-tool недоступен — честно
  сказать пользователю, что без живого пайплайна оценка невозможна.
- ❌ Применять рыночные бенчмарки из других стран/агентств. Числа агентства
  CNS — единственный источник истины (см. `projects_metadata.txt`).
- ❌ Обещать конкретику, если top-аналог имеет score < 0.55.
  Корректная формулировка: «Прямого аналога в нашем архиве нет, оценка
  построена на допущениях X и Y; зафиксируем после стартового созвона».

## Пример сценария

```
User: "Привет, у меня сеть автомоек в Алматы. Хочу единый сайт
       с записью онлайн и интеграцией с iiko. Сколько и сроки?"

Assistant action:
  1) call search_analogues("Сайт сети автомоек с онлайн-записью
     и интеграцией с iiko", k=3)
  2) если top.score ≥ 0.55 → call estimate_from_brief(<тот же текст>)
  3) ответить пользователю: тип проекта, найденные аналоги (project_id +
     score), 2–3 варианта со стоимостью и сроком, оговорки если слабые
     аналоги
  4) предложить: "Запустим полный пайплайн на http://localhost:8000 —
     получите редактируемое КП в PDF за 30 секунд."
```

## Связи

Skill работает поверх:

- MCP-сервер `cns-proposal` (см. `app/mcp_server.py`, конфиг `mcp.json`)
- LangGraph пайплайн (см. `app/pipeline.py`) — для полного КП через веб
- RAG-индекс из 6 проектов агентства (см. `app/rag/`)

Стандарт: SKILL.md по спецификации Claude Code (frontmatter + markdown
тело). Триггер прописан в `description` — Claude Code автоматически
загружает skill при совпадении.
